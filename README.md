# Smart Pantry Manager

## Desciption
This application is a pantry manager that stores ingredients and recommends recipes that can be made from the ingredients in your pantry. 
It only suggests recipes that can be made once a user has all the required ingredients in its pantry. 

## Database (SQLite):
SQLite was chosen for this application as it is lightweight and already built into the API of Android. 
This makes it much easier as there is no need for a physical database server installation. SQLite stores the database information locally on the device so that when the application is opened and closed the data persists. My application is small and does not have big footprint, which makes SQLite well suited for this project.

## Features:
- Add ingredients
- Edit existing ingredients
- Delete ingredients from the pantry.
- View ingredients in the pantry

## Technologies:
- Android Studio
- SQLite
- Java

## How to run:
### Step 1: To run the application you have to import the project into Android Studio.
### Step 2: Use the device manager to startup an Android emulator. 
### Step 3: Click the run button in Android Studio.
The application will start my installing the application automatically on the Android Emulator. 
After the application runs you will be presented with the home screen.
